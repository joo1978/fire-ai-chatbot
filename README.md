# 소방업무 AI 챗봇

소방 법령·업무절차·질의회신을 자연어 질문과 분야별 탐색으로 확인하는 서비스 제안용 웹 시제품입니다.

- 공개 시제품: https://joo1978.github.io/fire-ai-chatbot/
- 현재 범위: 검증된 12개 시연답변과 키워드 검색
- 현재 제외: 생성형 AI API, 데이터베이스, 로그인, 개인정보 저장
- 주의: 공식 서비스가 아니며 실제 적용 전 최신 법령과 대상물 현황을 확인해야 합니다.

배포 및 기술 범위는 [GITHUB_PAGES.md](GITHUB_PAGES.md)를 참고하세요.
